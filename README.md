# frootbox/skeleton

The starting point for a new website with
[Frootbox](https://github.com/Frootbox/frootbox). It brings the core, the
backend, the base theme and the official modules.

```bash
composer create-project frootbox/skeleton my-website
cd my-website
php bin/frootbox install
```

Then follow [Installation](https://github.com/Frootbox/frootbox/blob/main/documentation/getting-started/installation.md).
The new project has an `AGENTS.md` with the rules of a Frootbox website
for coding agents. This README, the license and `.gitattributes` stay
behind: the website belongs to you.

## Source and issues

This package is developed in the [Frootbox monorepo](https://github.com/Frootbox/frootbox)
and mirrored here read-only. Questions, bugs and ideas go there, see the
[documentation](https://github.com/Frootbox/frootbox/tree/main/documentation).
